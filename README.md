# interactor-test-fbx-sketchfab-02

A test corpus of third-party FBX models with reference meshes, for checking an FBX importer against known output.

## What it is for

Each artist's folder holds the models as published, a JSON record of each model's title, author, source and licence, and reference meshes of chosen animation frames to compare an import against.

## Licence

Each model is under the licence its JSON record names, CC BY 4.0, and is attributed to the author and source that record gives.
